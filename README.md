# 🎬 CineSearch

Aplicação web para busca e descoberta de filmes, desenvolvida para a disciplina de **Desenvolvimento Web** na Unibrasil.

## 🌐 Acesse o Projeto

👉 [cinesearchunibrasil.netlify.app](https://cinesearchunibrasil.netlify.app/)

## ✨ Funcionalidades

- Busca de filmes por nome
- Listagem de filmes em alta
- Suporte a múltiplos idiomas (PT/EN)
- Interface responsiva e intuitiva

## 🛠️ Tecnologias

- **HTML5** — estrutura e semântica
- **CSS3** — estilização e responsividade
- **JavaScript** — lógica e consumo de API
- **[OMDB API](https://www.omdbapi.com/)** — dados e informações dos filmes

## 📁 Estrutura do Projeto

CineSearch/

## 🚀 Como Rodar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Beatrys-lira/CineSearch.git
   ```
2. Abra o arquivo `index.html` no seu navegador.

> Não requer instalação de dependências.
