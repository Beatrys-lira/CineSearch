# 🎬 CineSearch

Aplicação web para busca de filmes, permitindo ao usuário pesquisar e descobrir filmes de forma rápida e intuitiva.

## 🖥️ Demonstração

- cinesearchunibrasil.netlify.app

## ✨ Funcionalidades

- Busca de filmes por nome
- Exibição de informações como título, ano e poster
- Interface responsiva e agradável

## 🛠️ Tecnologias

- **HTML5** — estrutura e semântica
- **CSS3** — estilização e responsividade
- **JavaScript** — lógica e consumo de API
- **[NOME DA API]** — dados dos filmes _(complete com o nome correto)_

## 📋 Pré-requisitos

- Navegador moderno
- Chave de API do **[OMDB API]**
